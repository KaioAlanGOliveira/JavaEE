# JavaEE
Java WEB -

Agenda de Contatos

Aplicação web simples para gerenciamento de contatos, desenvolvida com **JSP + Servlets + MySQL**.

## Funcionalidades

- Cadastrar novo contato
- Listar todos os contatos
- Editar contato existente
- Excluir contato (com confirmação)
- Validação básica de formulário

##  Tecnologias Utilizadas

- **Backend**: Java, JSP, Servlets
- **Banco de Dados**: MySQL
- **Frontend**: HTML5, CSS3, JavaScript
- **Servidor**: Apache Tomcat (recomendado)

##  Estrutura Principal

- `index.jsp` → Lista principal de contatos
- `novo.html` → Formulário de cadastro
- `editar.jsp` → Formulário de edição
- `Dao.java` → Camada de acesso a dados (CRUD)
- `JavaBeans.java` → Modelo de dados
- `web.xml` → Configuração da aplicação

##  Banco de Dados

Banco: `catequese`  
Tabela: `contato` (idcon, nome, fone, email)
